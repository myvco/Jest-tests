Jest Tests – React Registration App

Application React avec :

 Formulaire avec validation complète

 Stockage des utilisateurs dans localStorage

 Page d’accueil affichant les utilisateurs enregistrés

 Tests unitaires avec Vitest + Testing Library

 Tests end-to-end avec Cypress

 Documentation générée avec JSDoc

🚀 Installation
npm install

🖥️ Lancer l'application en développement
npm run dev


Application disponible sur :

http://localhost:5173

🧪 Tests unitaires (Vitest)

▶️ Lancer les tests une fois :
npm run test

▶️ Générer le coverage :
npm run coverage

Le rapport sera généré dans :

/coverage

🌐 Tests End-to-End (Cypress)

▶️ Lancer Cypress :
npm run cypress

Puis sélectionner :

E2E Testing → Chrome

📚 Documentation JSDoc

La documentation est générée automatiquement.

▶️ Générer la documentation :
npm run docs

La documentation sera disponible dans :

/docs
